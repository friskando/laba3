# Задание 1

### Текст задачи

На основе данного списка строк получить новый, где к каждой строке в начале

дописан заданный символ. (seq.map)

### Алгоритм решения

1. Выбираем задание из 2 предложенных
2. при выборе варианта осуществляется проверка на корректный ввод посредством кейса и проверки на преобразование в int если первая часть прошла успешно проверка на 0  
3. Запрашиваем у пользователя  количество строк через отдельную рекусривную функции с проверкой на ввод (реализована проверка через словарь и кейс попытку преобразовать в int)
4. после успешной проверки запрашиваем значение К (нам без разницы какое оно будет хоть string хоть int) оно всегда strig\*
5. выводим сколько пользователь заказал строк
6. добавляем в последовательность значения с помощью for (так же значения будут string)
7. через функцию uni (униикация\*) используем seq map для извлечения значений из последовательности и преобразовываем в другую функцию add для соединения двух стринговых значений и возвращаем новые значения с + К 
8.  выводим через через функцию вывода

# Задание 2

### Текст задачи

Список содержит строки. Найти количество строк заданной длины (seq.fold)

### Алгоритм решения

1. Выбираем задание из 2 предложенных
2. при выборе варианта осуществляется проверка на корректный ввод посредством кейса и проверки на преобразование в int если первая часть прошла успешно проверка на 0
3. Аналогично с первым запрашиваем кол строк
4. выводим сколько пользователь попросил строк для ввода
5. аналогично первому заданию добавляем значения в последовательность 
6. после ввода данных с знаениями пользовтаеля передаем эту последовательность в функцию для подсчета длины его элементов
7. запрашиваем у пользователя с какой длиной строку будем искать аналогично первому заданию проверяем на корекктный ввод
8. с помощью вспомогательной функции len сравниваем сколько элементов в последовательности содержат искомое значение (через аккумуляторную анонимную функцию)
9. в спомогательной функции через seq fold считаем сколько значений имеют равную длину искомой
10. выводим так - же т.к это последовательность у нас запрашивает заново ввод
